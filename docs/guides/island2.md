# ISLAND-2

Zone: ISLAND. Vehicle: car. Laps: 3.

Edit `map/island2/plan.json` or its `tools/map/author_island2.py` generator.

Route, checkpoints, alternate routes, hazards and boss configuration are in the plan's `skyrally` block. Material variants live in `assets/materials/`. Run map tests before rebuilding with the map compiler and adapter. This guide replaces private visual production references, not the shipped game assets.
